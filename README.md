### Java-Based Energy Consumption & Peak Demand Analytics

Developed a Java-based energy analytics program within the Niagara 4 Building Management System (BMS) to automate utility consumption calculations and peak demand monitoring using live operational data.

The program incorporates four analytical components:

- **15-Minute Consumption:** Calculates incremental utility consumption at 15-minute intervals.
- **Daily Consumption:** Aggregates consumption over a 24-hour period with automated daily resets.
- **Monthly Consumption:** Tracks cumulative monthly consumption with calendar-based resets.
- **15-Minute Peak Demand:** Identifies and retains the highest interval demand recorded throughout each day.

The solution incorporates totalizer differential calculations, scheduled triggers, persistent state management, and automated reset logic. This project demonstrates the practical integration of Java programming, industrial IoT, time-series data processing, and energy analytics to support operational efficiency, utility reporting, and data-driven decision-making.
